CAD 转三维网页 —— 使用说明
================================================================

一句话：把 SolidWorks 导出的 STEP 变成一个人人能用浏览器打开的
三维网页，不装 CAD、不用联网、手机也能看。


【怎么用】（两种方式，任选）

  方式一：双击「转换.cmd」，在弹出的窗口里选中模型文件（可多选），确定。
  方式二：把模型文件直接拖到「转换.cmd」的图标上松开。

  然后等几秒到几分钟，模型旁边会出现「原文件名_三维查看.html」，
  并且自动用浏览器打开。

  支持：STEP / STP / IGES / IGS / STL / OBJ / PLY / 3MF / GLB


【发给别人】

  那个 HTML 是单个文件，查看器代码和模型数据都打包在里面。
  微信 / QQ / 邮件 / 网盘发过去，对方双击就能看，什么都不用装。
  手机微信里点开也能转着看（微信内置浏览器支持）。

  注意：
  · 用「发送原文件」发，不要截图、不要转发成链接。
  · 邮件附件对 .html 有限制时，先压缩成 .zip 再发。
  · 文件里就是模型本体，谁能打开谁就能提取几何，敏感模型慎发。


【文件夹里每个文件干什么】

  转换.cmd            主入口：按 CAD 原始坐标转换
  转换_上下翻转.cmd   模型上下颠倒时用这个（翻转 180°）
  install-deps.cmd    依赖出问题时双击跑一次
  make_viewer.py      主程序：网格化、上色、压缩、打包
  pick_files.py       双击 转换.cmd 时弹出的选择框
  build_html.py       生成单文件网页（内嵌查看器）
  colorize.py         给每个零件分配不同颜色
  vendor\             model-viewer 查看器本体（约 1 MB）
  说明.txt            就是本文


【如果出来的模型上下颠倒】

  用「转换_上下翻转.cmd」重做一次。

  判断方法：浏览器里看正上方是不是一大块平板（地板/底板）。
  是的话就说明模型在 CAD 里是 Y 轴朝下的，用翻转那个。

  我们这几个项目的经验：
  · 总装.STEP        —— 需要翻转
  · Steam Equipment —— 本来正放，不用翻
  · 1.STEP          —— 不用翻
  拿不准就先不翻，看一眼再决定，重做一次也就几十秒。


【网页里怎么操作】

  鼠标   ：左键拖动 = 旋转 ｜ 右键或 Shift+左键拖动 = 平移
           滚轮 = 缩放 ｜ 双击按钮 = 全屏
  触摸屏 ：单指拖动 = 旋转 ｜ 双指拖动 = 平移 ｜ 双指捏合 = 缩放

  按钮   ：复位（回到初始角度）、切换灰模（发给客户时用）、
           自动旋转、全屏

  视角完全自由：上下左右都能转到，也能放大后平移去看某个局部。
  按钮在底部时，在按钮条空白处拖动一样能旋转。


【精度和体积怎么调】

默认参数多数模型够用。要改就在命令行加参数：

  --tol-linear    线性公差，相对包围盒，默认 0.0004。调小 = 更精细、更大
  --tol-angular   角度公差，单位是【弧度】，默认 0.15
  --target-mb     压缩后模型体积上限，默认 12 MB，超了会自动放粗重试
  --mono          不分零件上色，用统一白模
  --flip-axis     none / x / z，翻转整个装配
  --out           指定输出路径

  特别提醒：--tol-angular 的单位是弧度，不是角度。
  软件默认的 0.5 弧度 = 28.6 度，圆柱面只剩 12 段，看着明显发棱；
  0.15 弧度（约 8.6 度，圆柱至少 42 段）就顺了，文件只大一点。

  体积太大时用 --target-mb 调大目标（比如 20），比手动改精度省事。
  超大总装（几百个零件、四五十 MB 的 STEP）转换要几分钟，属正常。

  程序不会为了凑体积把模型压烂：圆管的角度精度默认最多放到 0.3 弧度
  （圆柱 21 段），再放粗只能省 5% 以内时就自动停手，保留更精细的那版。
  所以超大模型可能达不到目标体积，这是有意的取舍。
  真要小巧的预览版，用 --target-mb 4，它会允许把圆管压粗。


【依赖】（这台电脑已经装好，换电脑要重新装）

  Python 3.9 以上
  pip install cascadio trimesh
  gltfpack（压缩用，可省略）：npm install -g gltfpack
  没有 gltfpack 也能转，只是文件大约翻倍。

  这台机器上有好几个 Python（3.12 装了依赖、3.13 没装、还有微软商店的
  占位程序）。两个「转换.cmd」会自动挑出真正装了依赖的那个，
  并在窗口第一行打印用的是哪一个，不用你操心。

  换电脑第一次用：双击 install-deps.cmd，它会自己装齐。


【原理】

  STEP ──OpenCASCADE 网格化──▶ GLB
       ──每个零件一个材质并上色──▶ 彩色 GLB
       ──顶点焊接 + 量化压缩（gltfpack）──▶ 小体积 GLB
       ──base64 内嵌 + 查看器一起打包──▶ 单文件 HTML

  1. STEP 是数学曲面，浏览器只认三角网格，所以必须网格化一次。
  2. 按零件上色，零件边界一眼能分清，这是"看得清"的关键。
  3. 量化压缩不减三角形，只降低坐标精度（肉眼看不出来）。
  4. 查看器（Google model-viewer，约 1 MB）也内嵌进 HTML，
     所以成品断网也能打开，不会因为外部链接失效白屏。
  5. 中间文件放系统临时目录，做完自动清理。
  6. 新版本先写临时文件、成功后才替换：中途失败不会毁掉上一次的成品。


【常见问题】

  问：双击 转换.cmd 没反应？
  答：正常，它会先弹一个选文件的窗口（可能藏在其他窗口后面，
      看一下任务栏）。不想用选择框就直接把文件拖到图标上。

  问：提示 "No Python with the required packages"。
  答：双击 install-deps.cmd 装一次，装完再转。

  问：提示"看起来没有写完（末尾缺少 END-ISO-10303-21）"。
  答：STEP 还没导出完就拖过来了。等导出进度走完，或重新导出。

  问：提示"试了多种精度都网格化不出来"。
  答：文件可能只有标注没有实体，或者模型太大内存不够。
      关掉 SolidWorks / 浏览器再试；还不行就在 SolidWorks 里重新导出。

  问：对方打开是白屏。
  答：九成是文件没传完整（微信/邮件截断）。用网盘传原文件，或压缩成 zip。

  问：能变成在线链接让别人点开就看吗？
  答：可以，把 HTML 传到任意静态托管（Cloudflare Pages、GitHub Pages、
      阿里云 OSS 等）。但文件里就是模型本体，谁能打开谁就能提取。

  问：转出来的文件能不能再小？
  答：加 --target-mb 3 会让它自动放粗精度；或者在 SolidWorks 里删掉
      内部不需要的零件再导出。

  问：想改 .cmd 里的提示文字。
  答：千万别写中文。cmd 按系统代码页解析批处理，中文会变成乱码命令
      导致脚本报错。三个 .cmd 现在都是纯英文，就是这个原因；
      中文提示都放在 Python 脚本和本文件里。
